# Лабораторна робота №6
- Студен: Пономаренко Олександа
- Група: ІО-о51
- Номер в групі: 5

__Тема:__
Робота з колекціями в мові програмування Java

__Мета:__ 
Здобуття навичок у створенні власних та використанні
стандартних колекцій в мові програмування Java.

## Варіант завдання
1) С2 = 1 => Set
2) C3 = 2 => Двозв’язний список

## Опис завдання

У даній лабораторній роботі необхідно:

- створити типізовану колекцію;
- реалізувати інтерфейс "Set";
- використати двозв’язний список як внутрішню структуру;
- реалізувати всі методи інтерфейсу "Set";
- створити:
  - порожній конструктор;
  - конструктор з одним елементом;
  - конструктор зі стандартної колекції;

## Опис реалізації

У програмі реалізовано наступні класи:

- *Node* — вузол двозв’язного списку;
- *DoublyLinkedSet* — реалізація колекції "Set";
- *Main* — виконавчий клас програми;
- *DoublyLinkedSetTest* — набір модульних тестів.

### Особливості реалізації

У класі "DoublyLinkedSet" реалізовано:

- зберігання унікальних елементів;
- додавання елементів;
- видалення елементів;
- перевірку наявності елемента;
- очищення колекції;
- ітератор для проходження по колекції;
- підтримку Generic-типів;
- роботу через двозв’язний список.

## Опис тестів

__testAdd()__

Перевіряє правильність додавання елементів та заборону дублікатів.

__testRemove()__

Перевіряє коректність видалення елементів із колекції.

__testContains()__

Перевіряє наявність елемента у колекції.

__testConstructorCollection()__

Перевіряє роботу конструктора зі стандартної колекції.

__testClear()__

Перевіряє очищення колекції.

__Висновок__

У ході лабораторної роботи було реалізовано власну типізовану колекцію на основі двозв’язного списку.
Було створено реалізацію інтерфейсу "Set" із підтримкою Generic-типів.
Також було реалізовано всі основні методи колекції.
